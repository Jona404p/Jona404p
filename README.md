### VOUCH
**Document Intelligence & Writing Analytics Platform**
A web platform that analyzes both the final content of a document and the process behind its creation. / Plataforma web que analiza tanto el contenido final de un documento como el proceso de escritura.

- Rich-text editor with writing activity tracking and event recording
- Document versioning and reconstruction
- Evidence-based writing analytics and AI-assisted analysis
- Teacher-oriented assessment workflows

`JavaScript` `React` `Supabase` `AI Integration`

[🔗 Live demo: docvouch.com](https://docvouch.com/) · [📂 Repository](https://github.com/Jona404p/VOUCHI_INFO)

### AiPredict
**AI-Powered Football Prediction System / Sistema de predicción de fútbol con IA**
An experimental app for football match analysis that combines structured sports data with locally deployed language models (Ollama).

- Match outcome analysis (1X2), goals and market analysis
- Local LLM integration and sports data processing
- Prediction interface and application architecture

`Python` `Docker` `Ollama`

[📂 Repository](https://github.com/Jona404p/AiPredict/)

### BTC Intelligence AI
**Bitcoin Market Analysis with Local AI / Análisis de Bitcoin con IA local**
A local AI-assisted research platform for Bitcoin: technical indicators, market structure, derivatives, news, and a knowledge base queried via RAG.

- Technical analysis, price action, and market structure (BOS/CHOCH)
- Binance market data integration through CCXT
- Document knowledge retrieval with RAG (Qdrant vector database)
- Trading risk analysis and paper-trading tools

`Python` `FastAPI` `Next.js` `Ollama` `Qdrant` `CCXT`

[📂 Repository](https://github.com/Jona404p/btc-intelligence-ai/)
